# v0.0.7 リリースノート

**リリース日**: 2026-09-23

## 🔒 セキュリティ: 依存パッケージの脆弱性を解消

### 背景
`npm audit` で Next.js 本体を含む依存パッケージに複数の脆弱性が検出されていた。
うち Next.js の 2 件は **critical**（重要度: 最高）であり、解消が必要だった。

| 重要度 | 件数 |
|--------|------|
| critical | 1 |
| high | 6 |
| moderate | 3 |
| low | 2 |
| **合計** | **12** |

### 主な脆弱性

| パッケージ | 重要度 | 内容 |
|-----------|--------|------|
| next | critical | Image Optimization API の AVIF 処理における未認証 RCE（GHSA-2xp9-vwfh-vxw4） |
| next | critical | Windows ホスト時の未認証 RCE（GHSA-p293-qw3h-jr36） |
| postcss | high | `</style>` 未エスケープによる XSS / sourceMappingURL 経由の任意ファイル読み取り |
| sharp | high | libvips / libheif 由来の脆弱性（CVE-2026-33327 ほか） |
| browserslist | high | クエリ結果キャッシュ未解放によるメモリ枯渇（OOM） |
| fast-uri | high | バックスラッシュ・不正 IPv6 正規化を悪用した SSRF / ホスト混同 |

### 対応内容

| 項目 | 対応前 | 対応後 |
|------|--------|--------|
| next | 16.2.11 | **16.3.6** |
| sharp | 0.34.5 | **0.35.4** |
| postcss | 8.4.31（next 同梱）/ ^8 | **^8.5.23** |
| tsx（tailwindcss 経由） | 4.21.0 | **4.23.15**（`overrides` で固定） |
| esbuild（tsx 経由） | 0.27.3 | **0.28.2** |
| `npm audit` 検出件数 | 12 件 | **0 件** |

### Docker ビルドの再現性向上
`Dockerfile` の依存インストールで `package-lock.json` を参照していなかったため、
ビルドのたびに semver 範囲内で最新版が解決されていた（バージョンが固定されない）。
lockfile をコピーして `npm ci` を使うように変更し、
**脆弱性修正済みのバージョンがそのまま本番イメージに反映される**ようにした。

## 検証結果

| 項目 | 結果 |
|------|------|
| `npm audit` | 0 vulnerabilities |
| `npm run build` | 成功（Next.js 16.3.6 / Turbopack） |
| 本番サーバー起動 | 成功（`/` が HTTP 200・約 20 KB を返す） |
| TypeScript 型チェック | `src/components/ui/*` の未使用コンポーネントに既存エラーあり（本変更とは無関係・`next.config.ts` で `ignoreBuildErrors: true` のため影響なし） |
