# v0.0.6 リリースノート

**リリース日**: 2026-08-04

## ☁️ インフラ移行: Firebase App Hosting → Cloud Run（東京リージョン）

### 背景
AI Studio からボタンでデプロイしていた Firebase App Hosting は、US リージョン固定かつ
アイドル時もインスタンスが常時待機するため、アクセスがほぼないにも関わらず月約2,000円の
コストが発生していた。

### 移行内容

| 項目 | 移行前 | 移行後 |
|------|--------|--------|
| プラットフォーム | Firebase App Hosting | Cloud Run（手動デプロイ） |
| リージョン | US 固定 | asia-northeast1（東京） |
| min-instances | 未指定（常時待機） | 0（スケールゼロ） |
| max-instances | 1 | 1 |
| メモリ | デフォルト | 512 MiB |
| CPU | デフォルト | 1 vCPU |
| 想定月額 | 約2,000円 | **約30円** |

### 追加ファイル

| ファイル | 説明 |
|---------|------|
| `Dockerfile` | マルチステージビルド（deps → builder → runner） |
| `.dockerignore` | Docker ビルドの除外設定 |
| `cloudbuild.yaml` | Cloud Build 構成 |
| `docs/cloudrun-deploy.md` | デプロイ手順書 |
