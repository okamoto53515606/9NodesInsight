# v0.1.1 リリースノート

**リリース日**: 2026-11-12

## 🔒 セキュリティ: Node.js の 2026-11-11 更新を取り込み、npm audit を 0 件に

### 背景

2026-11-11（米国時間）に Node.js のセキュリティ更新が公開された。
修正版は 26.13.1 / **24.22.3** / 22.23.5 で、high 7 件・medium 6 件・low 3 件の
計 16 件を修正している。本アプリの本番イメージは `node:24-slim`（Node.js 24 系）で
Next.js の Node サーバーを稼働させており、以下の high が該当する。

- HTTP/2: 認証不要のクライアントがプロセスを異常終了させられる（CVE-2026-123863）
- TLS: ハンドシェイク処理の不具合でリモートからプロセスを終了させられる（CVE-2026-126051）
- HTTPS: 認証なしのクライアントが他接続のメモリを読み取れる可能性があり、
  TLS 秘密鍵や他ユーザーのリクエストが含まれうる（CVE-2026-123864）
- HTTP/2: 解放済みメモリが相手に送られる不具合（CVE-2026-123866）

あわせて `npm audit` に high 1 件（zod）と moderate 2 件
（postcss-selector-parser）が残っていたため、依存関係の更新も行った。

### 対応内容

| 対象 | 対応前 | 対応後 | 内容 |
|------|--------|--------|------|
| `Dockerfile` ベースイメージ（deps / builder / runner） | `node:24-slim`（v24.22.1） | **`node:24-slim`（v24.22.3）** | マイナー/パッチは固定せず、再ビルドで常に最新パッチを取得 |
| `cloudbuild.yaml` | `docker build` | `docker build --pull` | ベースイメージの最新パッチを確実に取り込む |
| `package.json` `engines.node` | 未設定 | **`>=24.22.3 <25`** | 修正版未満の Node.js でのビルドを警告。マイナーは固定しない範囲指定 |
| `next` | 16.4.2 | **16.4.6** | 16 系の最新パッチ |
| `zod` | 3.25.76 | **4.6.7** | GHSA-mrhx-c7xc-m3w5（high）の修正版。v3 系に修正版はない |
| `@hookform/resolvers` | 4.1.3 | **7.0.6** | zod 4 対応（`zodResolver` の import パスは変更なし） |
| `postcss-selector-parser`（overrides） | 6.0.10 / 6.1.4 | **6.1.6** | GHSA-rj75-hqrm-r3gf（moderate）の修正版 |
| `@types/node` | ^20 | **^24** | 実行ランタイム（24 系）と型定義を揃える |
| その他（semver 範囲内） | — | — | `react-hook-form` 7.92.0 / `postcss` 8.5.32 / `tailwind-merge` 3.7.0 / `@radix-ui/*` / `@tailwindcss/typography` 0.5.20 / `autoprefixer` 10.6.2 |

- `@tailwindcss/typography` は `postcss-selector-parser` を `6.0.10` に完全固定して
  いるため、`overrides` で 6.1.6 に差し替えた。
- zod 4 系への更新に伴い `@hookform/resolvers` を 7 系へ更新した。本アプリで使って
  いるのは `z.object` / `z.string` / `z.array` / `z.infer` のみで、いずれも
  zod 4 で互換の API である。
- アプリケーションコードのロジック変更はない。
