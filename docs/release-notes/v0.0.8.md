# v0.0.8 リリースノート

**リリース日**: 2026-10-20

## 🔒 セキュリティ: Next.js 2026-10-14 アドバイザリと npm audit の脆弱性を解消

### 背景

2026-10-14 に Vercel から Next.js の緊急セキュリティアップデート（v16.4.1）が公開された。
本アプリは App Router + Server Actions を利用し、かつ glibc ベースの `node:22-slim` 上で
Image Optimization を有効にしているため、公開された 3 件はいずれも本番環境に該当する。

| アドバイザリ | 重要度 | 内容 | 本アプリへの該当 |
|-------------|--------|------|------------------|
| GHSA-673q-mjm6-r5xr | critical | Cache Components の `use cache` が型付き配列を返す場合の未認証 RCE | 該当なし（Cache Components 未使用）だが、ワークアラウンド無しのため更新対象 |
| CVE-2026-96889 / GHSA-2464-fhr4-w9xw | critical | Image Optimization API（SVG）経由の未認証 RCE。glibc 環境かつ `sharp` < 0.35.5 が対象 | **該当**（`node:22-slim` = glibc、`sharp` 0.35.4） |
| GHSA-p3m5-59mp-jv5r | high | 細工したリクエストによる Server Actions の CPU 枯渇 DoS | **該当**（`src/app/actions.ts` で Server Actions を使用） |

あわせて `npm audit` で Next.js 本体の 6 件（SSRF・キャッシュポイズニング・Draft Mode 情報漏えい等）、
および `sharp` / `proxy-addr` / `source-map-js` の脆弱性が検出されていた。

| 重要度 | 対応前 | 対応後 |
|--------|--------|--------|
| critical | 1 | 0 |
| high | 9 | 5 |
| moderate | 4 | 4 |
| **合計** | **14** | **9** |

### 対応内容

| パッケージ | 対応前 | 対応後 | 内容 |
|-----------|--------|--------|------|
| next | 16.3.6 | **16.4.2** | 上記アドバイザリ 3 件 + `npm audit` 検出 6 件を解消 |
| react / react-dom | 19.2.1 | **19.3.1** | Server Functions の DoS（GHSA-h3gv-c5rc-p453、修正版 19.2.9 / 19.3.1） |
| sharp | 0.35.4 | **0.35.5** | CVE-2026-96889（librsvg 由来のメモリ破壊 → RCE） |
| proxy-addr | 2.0.7 | **2.0.8** | IPv4-mapped IPv6 の信頼サブネット判定を悪用した IP スプーフィング |
| source-map-js | 1.2.1 | **1.2.2** | 索引付き source map のセクションオフセットによるイベントループ DoS |
| @modelcontextprotocol/sdk | （optional peer として導入） | **導入されない** | OAuth クレデンシャルの送信先制御不備。`@google/genai` の optional peer だったが本アプリでは未使用のため、`overrides` で固定したうえでツリーから除外 |
| @types/react / @types/react-dom | 19.2.1 | **19.3.0** | 実行時バージョンに追従 |

`sharp` / `proxy-addr` / `source-map-js` / `@modelcontextprotocol/sdk` は
間接依存のため `package.json` の `overrides` で修正版を固定し、
lockfile 更新後も修正版が解決されるようにしている。

### 未解消の検出項目（開発・ビルド時のみ）

`npm audit` に残る 9 件は、いずれも `tailwindcss` 3.x（devDependency）配下の
ビルドツールチェーンに限られる。実体は次の 2 件で、残りはその依存関係の連鎖。

| パッケージ | 重要度 | 内容 | 未解消の理由 |
|-----------|--------|------|--------------|
| braces | high | 深くネストしたパターンによるスタック枯渇 DoS | 修正版が未リリース（最新 3.0.3 が該当） |
| postcss-selector-parser | moderate | フラットセレクタ解析の二次計算量による CPU 枯渇 | 修正は 7.1.6 以降（メジャー更新）。`tailwindcss` 3.x / `@tailwindcss/typography` が 6.x に固定しており、上書きするとビルドが壊れるため保留 |

これらは本番イメージ（`output: 'standalone'`）に含まれないことを確認済み
（`.next/standalone/node_modules` に `tailwindcss` / `braces` / `postcss` は存在しない）。
