# v0.0.9 リリースノート

**リリース日**: 2026-10-23

## 🔒 セキュリティ: Node.js ランタイムを 24 系へ更新し CVE-2026-111497 を解消

### 背景

2026-10-21 に Node.js のセキュリティリリースが公開され、Brotli デコーダの
アウトオブバウンズ書き込みによりリモートコード実行が可能になる
CVE-2026-111497（High）が報告された。影響を受けるのは Node.js 22.x / 24.x / 26.x で、
修正版はそれぞれ 22.23.4 / 24.22.1 / 26.12.1。

本アプリの本番イメージは `node:22-slim`（Node.js 22.x）上で Next.js の
Node サーバー（`output: 'standalone'` の `server.js`）を稼働させており、
HTTP 応答の圧縮（`Accept-Encoding: br`）を扱うため、この脆弱性の影響範囲に含まれる。
`Brotli デコード` は外部入力（圧縮リクエスト/応答）に触れる経路であり、
公開エンドポイントを持つ Cloud Run サービスとして修正版への更新が必要と判断した。

### 対応内容

| 対象 | 対応前 | 対応後 | 内容 |
|------|--------|--------|------|
| `Dockerfile` ベースイメージ（deps / builder / runner） | `node:22-slim`（22.x） | **`node:24-slim`（v24.22.1）** | CVE-2026-111497 の修正版 24.22.1 を適用 |

- Node.js 24 系は LTS であり、`node:24-slim` はマイナーバージョンを固定しないため、
  以降の 24.x パッチ（セキュリティ修正を含む）もビルド時に自動で取り込まれる。
  2026-10-23 時点の `node:24-slim` は修正版の **v24.22.1**。
- アプリケーションコード・依存パッケージ（`package.json` / `package-lock.json`）は変更していない。
- `@types/node`（`^20`）はビルド時の型定義のみで実行時ランタイムには含まれないため据え置き。
