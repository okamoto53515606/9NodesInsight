# v0.0.5 リリースノート

**リリース日**: 2026-07-25

## 🔄 アーキテクチャ刷新: Genkit → Google GenAI SDK

### Genkit 廃止
- `genkit`, `genkit-cli`, `@genkit-ai/google-genai` を完全に削除
- `@google/genai` SDK で直接 Gemini API を呼び出す方式に移行
- **パッケージ数**: 793 → 273（-520）
- **脆弱性**: 74 → 7（-67）

### 二段階生成フロー

| Step | モデル | 役割 |
|---|---|---|
| ① 検索 | `gemini-2.5-flash-lite` | Google Search で各入力項目の客観的情報を収集 |
| ② 生成 | `gemini-3.5-flash-lite` | 検索結果を踏まえたプロフィール生成 |

### プロンプト強化

- 🔬 **バーナム効果対策**: 具体性・反証可能性を要求。誰にでも当てはまる抽象表現を禁止
- ⚠️ **ネガティブ分析の明示**: 矛盾・偏り・盲点の積極的指摘
- 🔍 **Google検索グラウンディング**: 入力された作品の客観情報（概要・テーマ・批評）を検索結果から補完

---

## 🐛 バグ修正（デプロイ後）

- **500エラー修正**: `'use server'` ファイルから Zod スキーマ等のオブジェクト export を除去し、async 関数のみに
- **マークダウン表示バグ**: モデルが `profile: |` プレフィックスを出力する問題をプロンプト修正 + コード側除去で対応
- **Cloud Run 403エラー**: ADC より API キーを優先させるため `apiKey` を明示指定
- **環境変数名**: `GOOGLE_GENAI_API_KEY` に統一（Cloud Run YAML と一致）

## 🎨 表示・UX改善

- Google 検索結果を**インラインスクロール表示**（常時表示、クリック不要）
- 検索失敗時はセクション自体を非表示
- 出力スキーマに `searchContext` を追加し、画面に表示

## ✍️ プロンプト改善（文体・表現）

- **ポップな文体**: 小学生にも読める言葉、漢字制限（往還・表象等を禁止）、TikTok風の軽いノリ
- **セクションタイトル刷新**: 「矛盾と盲点」→「でも、ちょっとブレてない？」等
- **総評の具象化**: 抽象的性格ラベル禁止、物・場所・キャラクターでの例えを推奨
- **例の削除**: モデルの自由度を上げるため具体例を除去
